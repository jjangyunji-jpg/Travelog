# 다이빙 컴퓨터 기록 불러오기

Travelog → 🤿 로그북 → **⌚ 다이빙 컴퓨터 기록 불러오기** 에서 파일을 고르면
수심·시간·수온·탱크 압력·기체·버디·**수심 그래프**가 그대로 들어옵니다.

## 지원 파일
| 형식 | 확장자 | 어디서 만드나 |
|---|---|---|
| UDDF | `.uddf` | 여러 다이빙 로그 앱의 공통 내보내기 형식 |
| Subsurface | `.ssrf`, `.xml` | 무료 앱 **Subsurface** (Windows·Mac·Linux·Android) |

## 가장 확실한 방법: Subsurface 거치기
Subsurface는 Shearwater, Suunto, Mares, Garmin Descent, Scubapro, Cressi, Oceanic 등
수백 종의 다이빙 컴퓨터에서 기록을 받을 수 있는 무료 프로그램입니다 (https://subsurface-divelog.org).

1. 노트북에 Subsurface 설치
2. **가져오기 → 다이빙 컴퓨터에서 가져오기** → 내 컴퓨터 제조사·모델 선택 → 블루투스 또는 USB로 다운로드
3. **파일 → 내보내기** → `UDDF` 선택 (또는 저장된 `.ssrf` 파일을 그대로 사용)
4. Travelog에서 그 파일을 선택

> 기종마다 연결 방식(블루투스/USB)이 다르니 Subsurface의 지원 목록에서 내 모델을 확인하세요.

## 불러올 때 자동으로 해 주는 것
- **스팟 연결**: 파일의 GPS 좌표 2km 이내 스팟이나 같은 이름의 스팟에 자동 연결, 없으면 새 스팟 생성
- **나라 판단**: GPS 좌표로 나라를 찾음 (좌표가 없으면 직접 선택)
- **중복 방지**: 같은 날 입수 시각이 10분 이내인 기록은 "이미 있음"으로 표시하고 체크 해제
- **단위 변환**: UDDF의 켈빈(K)·파스칼(Pa)을 °C·bar로 변환
- 불러온 뒤 생물·감정·사진은 기록을 열어 **수정**에서 추가

## 왜 블루투스로 바로 연결하지 않나요?
아이폰·아이패드의 Safari는 웹사이트가 블루투스 기기에 직접 연결하는 기능(Web Bluetooth)을 지원하지 않습니다.
그래서 모든 기기에서 동작하는 **파일 불러오기** 방식을 먼저 만들었습니다.
(안드로이드·PC의 Chrome에서는 직접 연결이 기술적으로 가능해, 필요하면 특정 기종부터 추가할 수 있습니다.)
